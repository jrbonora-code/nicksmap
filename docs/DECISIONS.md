## Additional requirements to implement

- Keep asset, community, parcel, facility/collateral and beneficial-owner evidence distinct; support reversibly merged identities.
- Keep actual, projected, broker-provided, vendor-estimated and reviewer-overridden values distinct.
- Snapshot every underwriting decision, its source versions and calculation version so it can be recreated later.
- Preserve unresolved facts and hard blockers alongside any score. Missing evidence does not become zero or a favorable assumption.
- Record original cost/schedule/return plans versus actual outcomes, including additional contributions and failed exits.
- Test authorization for exports, storage, background jobs and AI retrieval; UI hiding is insufficient.
- Treat benchmark uncertainty and sparse rural samples explicitly. Never infer returns or transaction motivation from property appearance.
